## 每日学习节奏

- **30-40 分钟** — 理论学习、看文章/视频、整理笔记
- **80-90 分钟** — 手写代码练习
- **10 分钟（可选）**— 用 FP 写法刷一道 LeetCode

## 编码约束

- [ ] 全程不使用 `for` / `while` 循环
- [ ] 优先使用纯函数，副作用集中隔离
- [ ] 数据不可变（不修改原数组/对象）
- [ ] 所有练习文件存放在对应 `exercises/week-XX/` 目录下

## 快速开始

```bash
# 进入某周的练习目录
cd exercises/week-01-pure-functions

# 运行单个练习
node 01-pure-functions.js
```
